# JUEGOS

Espacio principal para el proyecto de videojuego.

## Estructura

- [00_GENERAL](00_GENERAL/README.md): visión compartida, diseño, sistemas, mundo y planificación. Es la referencia común para las versiones 2D y 3D.
- [2D](2D/README.md): versión que desarrollaremos primero. Será una versión de alcance reducido, pero un juego completo y disfrutable por sí mismo.
- [3D](3D/README.md): reservado para una posible versión futura. No se desarrolla por ahora.

## Dirección inicial acordada

- Género de referencia: ARPG de fantasía oscura.
- Referencias: Diablo para la estructura de exploración y combate; el manhwa **L.A.G.** (habilidades pasivas ilimitadas) como referencia conceptual para la progresión de pasivas.
- Mundo: regiones conectadas, con libertad para explorar, caminos alternativos, secretos, mazmorras y zonas de distinto peligro.
- Dificultad de diseño: pensar primero en el modo Extremo. Los demás modos se podrán definir como configuraciones de las reglas comunes.
- Desarrollo: definir primero el juego que queremos; después decidir qué sistemas y contenidos entran en la versión 2D y cuáles quedan para una futura versión 3D.

## Estado

Este documento registra decisiones iniciales, no una especificación cerrada. Los detalles aún no definidos deben permanecer como pendientes hasta que se acuerden.
