# Repositorio de proyectos narrativos

Este repositorio contiene dos proyectos separados:

- **[UMBRAL/](UMBRAL/)**: archivo del proyecto original, con sus reglas, continuidad, fichas y diseños existentes. Se conserva como referencia independiente.
- **[NUESTRO-PROYECTO/](NUESTRO-PROYECTO/)**: proyecto nuevo en desarrollo, construido tomando UMBRAL como punto de partida conceptual, pero con reglas, personajes, progresión y pisos propios.

El `index.html` de la raíz se conserva en su ubicación para no alterar la página principal existente del repositorio.

**Importante:** el material de UMBRAL no se convierte automáticamente en canon del proyecto nuevo. Se consultará como referencia y cada elemento deberá ser seleccionado, adaptado o descartado durante el nuevo diseño.
