# VERSIÓN 2D

Primera versión que se desarrollará.

## Objetivo

Convertir la visión compartida de `../00_GENERAL/` en un juego 2D de alcance reducido, pero completo y disfrutable por sí mismo.

No todo lo imaginado para el juego definitivo tiene que entrar en esta versión. La selección se hará de forma consciente, documentando qué se adapta, qué se simplifica y qué queda reservado para el futuro.

## Áreas de trabajo

- [DOCUMENTACION](DOCUMENTACION/): decisiones y especificaciones propias de la versión 2D.
- [DISEÑO](DISEÑO/): diseño de niveles, interfaz, experiencia y presentación.
- [SISTEMAS](SISTEMAS/): implementación y diseño detallado de mecánicas.
- [PERSONAJES](PERSONAJES/): protagonista, personajes, enemigos y sus recursos.
- [DESARROLLO](DESARROLLO/): proyecto técnico, prototipos, código y pruebas.

## Estado

Todavía estamos definiendo el juego. No se ha elegido motor, lenguaje, resolución, estilo visual ni alcance definitivo.
