# Capítulos

**Estado:** todavía no hay capítulos escritos.

La narración comenzará cuando se aprueben:
1. El título o su alternativa.
2. El punto de vista y el lugar de apertura.
3. El primer conflicto local.
4. La presentación inicial del Héroe y Player.
5. Los límites de información que tendrán las diosas y los personajes.

Los capítulos aprobados se registrarán con número, título, estado y enlace.
