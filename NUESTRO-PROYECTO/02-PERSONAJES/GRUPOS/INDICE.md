# Índice de grupos recurrentes

Este directorio contiene registros de grupos que tengan continuidad o relevancia más allá de una aparición puntual.

Cada registro refleja la composición y evolución colectiva confirmadas, sin sustituir las fichas individuales de sus integrantes.

No crear un registro permanente para cada cooperación ocasional. Incorporar un grupo cuando su recurrencia, identidad o consecuencias lo justifiquen.

Los datos no confirmados deben identificarse como inferidos, desconocidos o propuestos; nunca presentarse como hechos aprobados.
